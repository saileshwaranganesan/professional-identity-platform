# Professional Identity Platform

## Overview

A production-quality platform for managing and publishing a professional identity through a secure administration experience and a public portfolio experience.

## Vision

Create a maintainable and extensible system where all portfolio content can be managed through the dashboard without modifying source code.

## Features

Manage profile, projects, skills, technologies, experience, education, certificates, resume, media, contact messages, SEO, and site settings through the admin experience.

## Technology Stack

React, TypeScript, Vite, Tailwind CSS, shadcn/ui, React Router, TanStack Query, React Hook Form, Zod, Axios, Framer Motion, Lucide React, Java 21, Spring Boot, Spring Security, Spring Data JPA, Hibernate, JWT, Flyway, MapStruct, Bean Validation, Swagger, and MySQL.

The repository is organized into application folders, documentation folders, diagrams, wireframes, assets, scripts, database, postman, and GitHub support files.
